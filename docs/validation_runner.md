# End-to-end human-validation runner

The repository has no organizer ground truth. This runner therefore generates **predictions only** from the supplied query workbook so a human can verify them.

It uses the existing query manifest, CLIP query encoder, frame index, multimodal evidence hooks, source-video temporal decoding, and fine CLIP frame scorer. It does not create or infer GT.

## Command

```bash
python -m aic2026.validation_runner \
  --queries /path/to/DanhSachTruyVanAIC_Chungket.xlsx \
  --manifest artifacts/dataset_manifest.parquet \
  --embeddings artifacts/clip_frames.npy \
  --videos-dir data/videos \
  --media-info-dir data/media_info \
  --caption-db data/caption.sqlite \
  --ocr-db data/ocr.sqlite \
  --output-dir artifacts/manual_validation \
  --top-k 100 \
  --radius-frames 24 \
  --max-decode-frames 96
```

Use `--faiss-index` when a persisted FAISS index is available. Use `--no-fine-score` for a faster retrieval-only diagnostic; the normal validation run keeps fine temporal scoring enabled.

To run one query while debugging:

```bash
python -m aic2026.validation_runner ... --query-id tkis-query-01
```

## Output

```text
artifacts/manual_validation/
├── tkis-query-01.json
├── ...
├── trake-04.json
├── vkis-09.json
└── run_summary.json
```

Each query file contains the original query record and up to 100 ranked model candidates. Candidate fields include video ID, semantic keyframe, temporal interval, timestamps and component scores.

The package explicitly contains:

```json
"official_ground_truth_available": false
```

No `video_match`, `frame_match`, or `answer_match` values are generated by this runner. Those are added only by the human-validation workflow in `manual_validation.py`.

## Recommended workflow

1. Generate the package with the current baseline.
2. Inspect Top-1, Top-5 and Top-20 first.
3. Extend to Top-50/Top-100 when the correct result is not found.
4. Verify the candidate in the original source video.
5. Record human labels separately with `manual_validation.py`.
6. Aggregate local diagnostics with `validation_report.py`.
7. Keep the same manually validated query set when comparing model/ranking changes.

These local diagnostics are not claimed to be official AIC2026 scores.
